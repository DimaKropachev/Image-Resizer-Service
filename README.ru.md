## Описание

**IRS** это веб-сервис, который получает изображение и преобразует его в изображения с размерами указанными в конфигурационном файле. Преобразованиями изображений занимаются воркеры, количество которых также указано в конфигурационном файле.

## Запуск

1. Клонируйте репозиторий командой:
```
git clone https://github.com/DimaKropachev/Image-Resizer-Service
```
2. Далее запустите **Docker Engine**. Если он не установлен, то можете скачать его [тут](https://www.docker.com/products/docker-desktop/)
3. Соберите образ из Dockerfile следующей командой:
```
docker build -f ./DockerFile -t irs .
```
4. Теперь запустите контейнер на основе собранного образа, используя команду:
```
docker run -p 8088:8088 irs
```

## Документация IPI 

|Endpoint|Метод| Описание|
|--------|-----|---------|
|/api/v1/upload|POST|загрузка изображения
|/api/v1/status|GET|получение статуса задачи, которая содержит нужное изображение|
|/api/v1/download|GET|скачать готовое изображение|
|/api/v1/delete|DELETE|удалить все задачи или конкретную|
|/api/v1/worker|GET|получить статистику определенного воркера|

### POST /api/v1/upload

Позволяет загрузить изображение на сервер для последующей обработки.

- **Формат запроса**: `multipart/form-data` с полем `image` (файл **JPEG** или **PNG**)
- **Ответ**: Уникальный идентификатор `task-id`

### GET /api/v1/status?id={task-id}

Позволяет узнать текущее состояние обработки изображения.

- **Формат запроса**: `id` - идентификатор задачи полученный при загрузке
- **Ответ**: поле `status` с одним из значений:
  - `pending` - задача находится в очереди
  - `processing` - воркер обрабатывает изображение
  - `done` - обработка завершена успешно
  - `failed` - произошла ошибка (будет описание в поле `error`)

### GET /api/v1/download?id={task-id}&size={size}

Возвращает готовое изображение или информацию о его готовности.

- **Формат запроса**: 
  - `id` - идентификатор задачи 
  - `size` - желаемый размер (название из конфигурационного файла)
- **Ответ**: Если задача не выполнена, вернется её статус. Если задача выполнена, то сервер пришлет файл `image/jpeg'

### DELTE /api/v1/delete?id={task-id}

Позволяет удалить одну или все задачи.

- **Формат запроса**: 
  - Если `id` передан, удаляется только указанная задача
  - Если `id` не указан, удаляются все существующие задачи

### GET /api/v1/worker?id={worker-id}

Возвращает информацию о работе конкретного воркера, обрабатывающего изображения.

- **Формат запроса**: `id` - числовой идентификатор воркера
- **Ответ**: Статистика воркера
